# 労働安全コンサルタント○×クイズ

労働安全コンサルタント試験の学習を支援する、無料のAndroid向け○×クイズアプリです。

## 主な機能

- ○×形式の問題演習
- 解答と正誤の確認
- 模擬試験と採点結果の表示
- 学習履歴の確認

## ダウンロード

公開用APKは、GitHubの「Releases」からダウンロードできます。

※ 現在、APKの公開準備中です。公開後にダウンロードできるようになります。

## インストールについて

Google Play以外からインストールするため、Android端末側でインストールの許可が必要になる場合があります。必ず本ページで案内する正規の配布ファイルをご利用ください。

## ご利用上の注意

本アプリは試験学習を支援するための非公式アプリです。試験の合格や問題・解説の完全な正確性を保証するものではありません。
